# ACE Credit

ACE Credit is the working repository for a financial empowerment ecosystem centered on the financial stability, economic mobility, stronger credit, income growth, entrepreneurship where appropriate, asset building, and long-term economic independence of Black women.

This repository will hold the project constitution, product and nonprofit strategy, grant intelligence, operational workflows, agent instructions, application architecture, compliance research, and implementation code.

## Current phase

**Phase 0 — Foundation and Governance**

Before application code is built, this project will establish:

- project constitution and non-negotiable rules;
- IACER specification standard;
- roadmap and measurable deliverables;
- agent/runtime boundaries;
- privacy, security, compliance, and human-approval gates;
- architecture decision process;
- definition of the long-term end state.

Implementation work should follow the instructions in `AGENTS.md` and the documents under `docs/` once the foundation branch is merged.
