## Freeze rule

After this batch, generic agent/runtime repositories should not modify G0 unless they materially outperform existing candidates on a specific unresolved requirement.

The project is no longer seeking “more agent capability.” It is seeking the smallest, most reliable implementation of the already-ratified machine:

```text
Personal Hermes
→ typed intent
→ governed CEO Hermes
→ bounded workers/deterministic services
→ evidence-backed grant intelligence
→ proposal/business/budget artifacts
→ QA/human review
```

Any candidate that adds generalized autonomy without reducing a known engineering gap should be classified REFERENCE/DEFER/REJECT.
