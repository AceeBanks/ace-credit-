## Method

The adapter (`prototype/g0/evidence/semantica_adapter.py`) projects canonical
evidence into a Semantica `KnowledgeGraph` as an OPTIONAL projection:

- node ids are the internal canonical ref ids (PROJ-001);
- Semantica never owns canonical identity (EVID-LAW-015, PROJ-003);
- canonical truth remains in the governed system of record;
- Semantica is a scoped, gitignored bake-off dependency (`.bakeoff/`).

All ten workloads from the charter were executed against both candidates.
Correctness is checked with real assertions (not `True` stubs); latency is
measured per workload. The harness records results to
`G0_B5_SEMANTICA_BAKEOFF_RESULTS.json`.

## Findings

1. **No correctness advantage**: both candidates answered all workloads
   correctly. The explicit substrate already encodes lineage, contradiction,
   dependency and tenant rules (GRAPH-001/002, INV-004..007).
2. **Real cost**: Semantica 0.6.6 pulls a large dependency tree
   (llms, vector stores, embeddings, MCP server, parse pipeline). That is an
   operational and supply-chain surface the project does not currently need.
3. **Real benefit**: for future semantic retrieval (Book 5 C10-C12 already
   define the vector index contract as a projection), Semantica could be a
   candidate accelerator — but nothing in the current evidence architecture
   requires it.
4. **Canonical truth is unaffected**: W7 proves projection rebuild from the
   canonical substrate; W10 proves degradation is graceful. Semantica can
   never become sovereign because canonical identity, ontology, evidence and
   authority remain in governed code and data.

## Verdict

**ADOPT_OPTIONAL_ACCELERATOR** — but only as a *deferred optional*:
the adapter contract is frozen now, the projection remains a defined role,
and activation requires the storage ADR (C14) decision plus the
external-component ledger entry. Recommendation to the ADR: **DEFER active
adoption** (keep the adapter; do not install Semantica in any runtime) until
a workload with measured recall/latency benefit at real data scale exists.

The C14 storage ADR consumes these measurements.
