# G0 Blueprint Amendment 001 — Georgia-First Early Drafting

**Document ID:** GS-G0-AMD-001  
**Version:** 1.0  
**Status:** ACTIVE PLANNING AMENDMENT — RATIFICATION FOLLOWS BOOK 0/1  
**Date:** 2026-08-24

## Purpose

Align the G0 master blueprint with two clarified implementation priorities:

1. the first client operates in **Georgia**, therefore Georgia replaces California as the preferred state-level proof jurisdiction; and
2. the client should see grant-writing capability as early as safely possible rather than waiting for Book 8.

## A. Georgia-first source priority

The product remains jurisdiction-agnostic. Early state fixtures, crawler tests and state-source adapters should preferentially use Georgia.

Initial Georgia source candidates:

- Georgia Governor’s Office of Planning and Budget / Georgia Grants Portal;
- OPB Active Grant Programs;
- OPB Awarded Grants;
- Georgia Department of Community Affairs grant/NOFO pages;
- Georgia Emergency Management and Homeland Security Agency grant pages;
- Georgia Environmental Protection Division grant pages;
- additional Georgia agency sources discovered by SourceRegistry onboarding.

California is no longer the default secondary-state proof in Book 8. It may remain a later coverage candidate.

## B. Early drafting milestone D0 — after Book 3

Once Books 0–3 are ratified, a bounded **Shadow Draft Harness** may create one mock grant proposal before the full Dual-Hermes protocol is complete.

Inputs:

- manually approved client-profile fixture;
- real/archived Georgia opportunity SourceSnapshot;
- manually validated requirement/evidence fixture;
- temporary bounded drafting workflow.

Rules:

- L2/internal only;
- clearly marked MOCK / NON-SUBMISSION;
- no external action;
- no unsupported factual invention;
- output retained as evaluation artifact, not production submission state.

Purpose:

- prove the writing direction early;
- surface missing ontology/data requirements before later books;
- give the client visible product progress.

## C. Early Hermes drafting milestone D1 — after Book 4

Once Dual-Hermes contracts and memory boundaries are ratified, CEO Hermes may produce the first Hermes-authored mock application through:

```text
Personal Hermes
→ IntentContract
→ CEO Hermes
→ bounded source/evidence context
→ draft
→ QA
→ OutcomeArtifact
→ Personal Hermes explanation
```

Still no submission/external action.

## D. Full production-shaped drafting milestone D2 — Book 8

Book 8 remains the end-to-end architecture proof using current real sources, deterministic eligibility, historical award/winner intelligence, organization verification, community evidence, evidence graph, application blueprint, drafting, QA, human review and audit.

Preferred state-secondary proof: **Georgia**, not California.

## E. Why this does not weaken architecture

Drafting itself is a low-consequence internal capability. Submission is the high-consequence action. The constitution therefore explicitly allows `application.draft*` under L2 while keeping `submission.execute`, certification and signing disabled.

This separation enables early client value without bypassing the enterprise control model.
